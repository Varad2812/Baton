# Baton: 2-minute demo script

Target length 2:00 (about 280 spoken words). Browser at 1440x900, tab open on https://baton-qxyj.onrender.com,
dark mode. Click **Reset demo** before recording. The guided tour follows this order, so you can also let it
drive and narrate over it.

| Time | Screen and action | Say |
|---|---|---|
| 0:00 | Landing page. Hero stack slowly turning. | "When a tech lead leaves, the repo stays but the knowledge goes. Baton hands over the project, not just the files." |
| 0:10 | Click **60-second tour**. Dashboard opens as Meera; the KPI row is highlighted. | "This is FestFlow, a college fest's ticketing app. Baton rebuilt its state from 40 sources: 67 claims, each graded by how well the records back it." |
| 0:25 | Next. Evidence Ledger, drawer open on *Auth moved from Firebase to Supabase*. | "Here is the receipt. Three independent sources, PR 84, chat and meeting notes, and the exact quote is highlighted in each. A claim is only verified if its quote string-matches the source. 127 of 127 quotes are valid." |
| 0:50 | Next. Conflicts, payment gateway card. | "Notes say Razorpay is final. A chat message says PhonePe trial credentials arrived. Baton doesn't pick a winner, it puts both quotes side by side." |
| 1:05 | Next. Interview, top question about the production database password. | "Some things were never written down. Baton asks Meera only what the records can't answer, ranked by risk. Her answers become testimony, badged as such, never passed off as fact." |
| 1:25 | Next. Switch to Prof. Rao. Review page, click **Approve as v1**. | "Prof. Rao reviews, resolves the conflict and approves. That freezes an immutable version. Meera can't approve her own handover." |
| 1:42 | Next. Switch to Arjun. Handover page, point at the hidden-claim placeholder. | "Arjun gets a plan built only from what he may see. Restricted sponsor data is hidden and he can request access. The model never received it." |
| 1:55 | Next. Trust page, leakage matrix. | "And the proof: canary strings planted in restricted files, zero leaks across all four roles. Baton: hand over the project, not just the files." |
| 2:00 | Back to the landing page or live URL on screen. | (silence, hold on URL) |

## Tips

- Say the numbers exactly as the screen shows them; the seed is deterministic.
- If the server is asleep, open the URL a minute before recording.
- The tour ends as Arjun. Use the "Viewing as" menu or **Reset demo** before the next take.
- Do not trigger a live pipeline run on camera; the cached result is the reliable path.
